# UpTrain Use Cases

This directory contains end-to-end use case examples demonstrating how to use UpTrain for evaluating real-world LLM applications.

## Available Use Cases

### 1. RAG Q&A System Evaluation (`rag_qa_system_evaluation.ipynb`)

A comprehensive example showing how to evaluate a Retrieval-Augmented Generation (RAG) based question-answering system.

**What you'll learn:**
- How to evaluate context relevance and quality
- How to assess response completeness and accuracy
- How to detect factual hallucinations
- How to implement safety checks (prompt injection, jailbreak detection)
- How to analyze evaluation results and identify issues

**Evaluations covered:**
- Context Relevance
- Context Conciseness
- Factual Accuracy
- Response Completeness
- Response Relevance
- Response Conciseness
- Response Consistency
- Prompt Injection Detection
- Jailbreak Detection

**Best for:** Developers building documentation Q&A systems, knowledge bases, or any RAG-based application.
